# Playdex

Playdex records gaming activity and delivers personal play-session insights.

## Language

**Gaming Provider**:
An external gaming system from which Playdex obtains activity, such as Steam or PSN.
_Avoid_: Provider when discussing notifications

**Notification Channel**:
A user-owned destination through which Playdex delivers notifications.
_Avoid_: Provider, chat

**Transport**:
The messaging system used by a Notification Channel, such as Telegram.
_Avoid_: Provider

**Destination**:
The transport-specific address identifying where a Notification Channel delivers messages.
_Avoid_: Chat ID when speaking generically
