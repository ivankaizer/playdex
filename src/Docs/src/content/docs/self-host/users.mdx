Every account is made from the command line on the server, with the same command:

```sh
docker compose exec app dotnet Api.dll create-user friend@example.com
```

| To | Run |
|---|---|
| Add a user | `create-user friend@example.com` |
| Add an admin | `create-user friend@example.com --admin` |
| Reset a password | `create-user` again with the same email |
| Make someone an admin | `create-user` again with `--admin` |

Without a piped password, it generates one and prints it once. `--admin` never removes admin rights. A new password signs that user out on every device.

Case doesn't matter in emails: `Me@example.com` and `me@example.com` are the same account.

Users can export or delete their own data in **Settings → Export or delete your data**.
