## Update

```sh
docker compose pull && docker compose up -d
```

The API migrates the database on start. To stay on one version, set `PLAYDEX_VERSION=sha-<commit>` in `.env`.

Installed before October 2026? The API now needs `CREDENTIALS_KEY`. Add it to `.env` (`openssl rand -hex 32`) and
download `docker-compose.yml` again before you update. On its first start the API encrypts the keys already stored.

## Back up

Everything is in Postgres. Dump it:

```sh
docker compose exec -T db pg_dump -U playdex -Fc playdex > playdex-$(date +%F).dump
```

Run that from cron and copy the dumps off the server.

## Restore

```sh
docker compose stop app
docker compose exec -T db pg_restore -U playdex -d playdex --clean --if-exists < playdex-2026-10-13.dump
docker compose up -d
```

Keep `.env` with your backups. `JWT_SECRET` only signs sign-ins, so losing it just signs everyone out. `CREDENTIALS_KEY` decrypts the Steam, PSN and OpenXBL keys in the dump: without it, each of those integrations needs its key entered again. `POSTGRES_PASSWORD` must match the database volume.
