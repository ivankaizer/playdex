Playdex for Windows records the PC games you play, backs up saves, and includes the console-style launcher. It works with any Playdex server.

<Steps>

1. In your Playdex, open **Settings → Connected services** and click **Create API key**.
2. Download [Playdex-Setup.exe](https://download.playdex.dev/windows/Playdex-Setup.exe) and run it.
3. Enter the two values from Settings:
   - **Playdex server:** `https://playdex.example.com/api`
   - **API key:** starts with `plx_`

</Steps>

To change the server later, open the app's **Settings → Playdex account**.

The server address must start with `https://`: the app sends your API key with every request and won't send it over plain HTTP. The one exception is a server on the same PC (`http://localhost`). The app keeps the key encrypted for your Windows user in `%LOCALAPPDATA%\Playdex\config.json`.

The installer and app updates always come from `download.playdex.dev`. Your play data only goes to your server.
