## What runs

| Service | What it is |
|---|---|
| `caddy` | HTTPS on ports 80 and 443. Sends `/api` to the API, the rest to the web app. |
| `ui` | The web app and admin console. |
| `app` | The API. Polls Steam, PlayStation and Xbox, and applies database migrations on start. |
| `db` | Postgres 16. All your data lives here. |
| `apprise` | Sends Telegram notifications. |
